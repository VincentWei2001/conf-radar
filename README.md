# Conference Radar

Conferences in architecture design, sustainable and low-carbon design, daylighting, glare, occupant behaviour,
building simulation, building performance, computational design and design research, with their deadlines and
EI (Ei Compendex) status.

**Page:** https://vincentwei2001.github.io/conf-radar/

- Deadlines are checked against each conference's official page; dates marked *aggregator* are unconfirmed.
- EI status means the proceedings venue is on Elsevier's Compendex source list (*series*), or that past volumes
  were indexed one at a time (*per volume*, no guarantee for the next one). A paper counts only once its record
  appears in Engineering Village.

This repository holds only the built page. It is regenerated by a private tool, so edit the source, not
`index.html`.
